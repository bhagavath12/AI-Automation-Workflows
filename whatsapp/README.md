# WhatsApp Automations

This folder contains the n8n workflows designed to handle WhatsApp-based marketing, customer support, and outreach. Below is a breakdown of each workflow and its purpose:

## 1. WhatsApp Chatbot (`whatsapp chatbot.json`)
An interactive AI-powered chatbot that responds to incoming WhatsApp messages. It logs interactions in Google Sheets, maintains conversation memory, and uses Google Gemini to generate contextual, intelligent replies to users. It acts as an automated assistant for customer inquiries.

## 2. Daily Campaign (`Daily campeign.json`)
A scheduled workflow designed to run daily to send out marketing campaigns or updates to a list of WhatsApp contacts. This workflow automates routine outreach and ensures consistent engagement with your audience.

## 3. WhatsApp Bulk Sending (`whatsapp bulk sending.json`)
A utility workflow for broadcasting messages to a large list of users at once. Useful for announcements, promotions, or newsletters sent directly over WhatsApp.

## 4. Post-Call Follow-up Sequence (`post-call followup sequence (1).json`)
A structured follow-up automation that triggers after a call with a lead or customer. It automatically sends a sequence of WhatsApp messages to nurture the relationship, provide additional information, or prompt the next steps in the sales funnel.

---
*Note: All API keys, tokens, and credentials have been redacted from these workflows for security.*
